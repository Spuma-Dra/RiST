# RiST (Rhythm Game Integrated Score Tool)

![RiST Logo](logo.png)

オンゲキをはじめとするSEGA音楽ゲームのスコア・レーティング・カードデータを統合管理する非公式Chrome拡張機能です。

---

## 🌟 主な機能

* **スコア一覧**:
  * 全難易度のスコア・ランプ・レーティング・Pスコアを一覧表示
  * 「お気に入り」「課題曲」「今日やる曲」など自由なカスタムタグ付け
  * バージョン、ジャンル、難易度、レベル、タグ、ランプ別の柔軟な絞り込み
* **レーティング分析**:
  * 新曲枠・ベスト枠・Pスコア枠の自動計算と詳細確認
  * レーティング推移グラフの表示
  * レーティング対象曲一覧の画像化
* **更新履歴**:
  * プレイ後のスコア伸び幅や新規AB/FC達成を一目で把握
* **カード所持図鑑**:
  * 所持カードのレベル・凸数・解花状態の管理と一覧表示
* **安全なローカル保存**:
  * 取得した全データはお手元のブラウザ（IndexedDB/Storage）にのみ安全に保存されます。

## 📥 インストール手順（初回）

1. 本リポジトリ右側の **[Releases](../../releases)** から最新の `RiST-extension.zip` をダウンロードします。
2. ダウンロードした ZIP ファイルを任意の場所に**解凍（展開）**します。
3. Google Chrome を開き、アドレスバーに `chrome://extensions` と入力して開きます。
4. 右上の **「デベロッパー モード」** を **ON** にします。
5. 左上の **「パッケージ化されていない拡張機能を読み込む」** をクリックし、解凍したフォルダを選択します。
6. インストール完了後、ツールバーのパズルアイコンから「RiST」を開いてご利用ください。

---

## 🔄 アップデート手順（バージョンアップ時）

※アップデートを行っても、**これまで取り込んだスコアデータやタグ設定はそのまま保持されます。**

1. **[Releases](../../releases)** から最新の `RiST-extension.zip` をダウンロードします。
2. ダウンロードした ZIP を解凍し、**現在読み込ませているフォルダの中身をすべて上書き**します。
3. `chrome://extensions` を開き、RiST のカードにある **「🔄（更新 / リロード）」アイコン** をクリックします。
